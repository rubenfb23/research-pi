DeepSeek V4.1 Flash vs GLM-5.3 Flash

Seven scenarios · Three controlled SDK profiles · Original results retained alongside GLM's structured-writer follow-up

Different tool versions: DeepSeek and the original GLM run used the prior tools. The new GLM run adds write_json and clearer tool descriptions for every profile. Tasks and requested settings match; this is a development comparison, not a controlled model ranking. One session per scenario/profile.

What changed

GLM's write_file content-type errors fell from 119 to 10. All 21 new scenario/profile cells were attempted across two retained runs. Pi base and ResearchPi with scientific tools score 95.24%; ResearchPi without those tools scores 73.81%.

An upstream timeout stopped the first run after 18 attempts. The failed synthesis attempt remains zero. A separate continuation executed only the three study cells that had not been attempted. Pi base and ResearchPi with tools reproduced their studies correctly. The instruction-only profile executed reproducible code but its run data failed the oracle and its submitted answer did not match fresh script output.

Seed completion type and numerical precision remain underspecified in the old frozen tasks. The scores have not been retrospectively adjusted.
