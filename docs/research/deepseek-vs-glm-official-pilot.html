Conditions and interpretation

600 seconds, 40 inference requests, 8,192 requested output tokens per response, two CPU cores and 3 GiB RAM per attempt. Model order alternates across tasks. The native harness retains filesystem, shell, research tools, code mode, compaction and retries. Inputs, prompts, evaluator code and runtime image were frozen before the retained model run.

Requested thinking is medium; effective wire fields are reported below. Each provider may implement reasoning differently. External browsing and package downloads are unavailable in this controlled environment; inference uses a credential-blind relay. The shared Python 3.11 stack is a local adaptation of CORE medium capsules, including legacy dependency repair.

Times are agent wall time and exclude setup and evaluator/replay time. Dollar amounts are SDK catalog estimates from reported usage, not verified account charges. Correct answers and replay consistency do not certify scientific validity or exclude hardcoded solutions. Published tasks may have appeared in training data. Exact model IDs are recorded, but provider weight revisions are not independently available. Binary completion is saturated in this three-task subset; continuous optimization and efficiency results remain descriptive, and a broader held-out suite is needed.

Full PaperBench, GPU training, Terminal-Bench, other harnesses and repeated-session inference remain pending. The other CORE tasks were not silently replaced by synthetic tasks.

Audit and reproduction

An initial six-request infrastructure run was rejected by OpenCode before generation because the relay omitted a required session header. Its artifacts remain private and marked invalid. After fixing transport and preventing unchanged NumPy code from passing on timing noise, the entire matrix was rerun. No unfavorable valid model attempt was replaced. The first local replay reader misattributed an earlier Transducer F header to the subsequent Transducer A power. A corrected block parser was calibrated against the full reference log and applied uniformly to both saved replay logs, without new model calls. Raw grades remain intact; the JSON records both raw and corrected local outcomes and the parser hash. Official answer scores were unchanged.

Both CORE reference executions and NumPy baseline probes passed before model runs. The corrected official grader accepted reference answers and rejected a deliberately wrong answer. All 88 existing tests and two relay/artifact tests passed during preparation; an additional regression test covers the multi-stage replay reader. Source review confirms both CORE solutions retain every original Python file and execute all five scripts for the legacy capsule.
